# 3D-console-renderer
This program is a console based program, as the tittle says, it's a fully functional 3D renderer, inside console, that's the great part, the most difficulties where found in all limitations console has to offer, i'm into 3D libraries, I tried OpenGL, but I wanted to see how difficult was to make it run in a Windows console, to learn how they work.

As the creator of this masterpiece, it took me months to complete it, I started at my 14 years of age and I'm publishing it after a year and a half of building this project. I admit it had lots of difficulties everywhere, but the 90% of it was just optimizing the console, even AI was used in this, I don't want to hide it, I think that if you already have admirable knowledge of something, AI can maximize your habilities in ways easier than years ago.

As optimization, it contains frustrum culling, backface culling, and specific Windows Console or Powershell optimization for printing and buffering, it has several systems like a great Windows Input system in console (without using conio.h), also for physics, and some GUI. This project remained untouched like 6 months ago, so I don't remember most of it, I'm seeing it after over a year and I'm still fascinated if what I did. Feel free to explore and question how it works, every part, my dream is that projects like this one could be seen by a lot of people interested in the topic, so try it!, I added some examples of projects, so feel free to test them all.

Important: Inside the examples folder, there is a text file named as "IMPORTANT AFTER YOU RUN ANYTHING.txt", and as it says, you should read it for avoiding being lost before running every example I have to offer.
