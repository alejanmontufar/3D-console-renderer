THIS PROGRAM IS WINDOWS CONSOLE BASED, SO TO SHOW CORRECTLY THE PIXELS ON CONSOLE YOU HAVE TO ZOOM OUT OR LOWER FONT SIZE (with ctrl -) (or with console configuration).
